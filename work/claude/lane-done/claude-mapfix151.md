# claude/mapfix151 - name plates never sit under map furniture
Code: src/map-plates.js nudgePlate (new), src/main.js drawMap plate loop, src/demo-end.js mapCaptionBox (caption box fixed before the boards), tools/demo-cut.mjs (pins the new demo-flag use).
At draw time a plate that meets the header, footer, compass, info card, touch NAMES chip, the junction's red 'CLEAR THE ...' box or the demo caption (or runs off the sides) moves to the nearest free spot (around its node or a short slide); it never lands on another shown plate; a plate whose node is off screen slides at most 14 px, else is not drawn. A clear plate is untouched, so mapclean's rules (names on selected + neighbours, hold C = all) are unchanged.
