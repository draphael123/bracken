3. Sweep mode is named 'sceptreSweepTell' / 'sceptreSweepCut' (not sweepTell): tools/tells.mjs sees one global mode name across creatures, and every other boss's sweepTell is red.
4. The perch reuses mode 'stunned' for DOWNED (so gqOpen's open plate and the existing stun plumbing apply) flagged e.q52Down; the swing tell (perchSwing) keeps the ward; she is not hittable by anything while in the bell, including from the cupola's stone.

6. Hatch = the shut deck hatch at cols 888-889 (TW.HATCH), the one drawn on the roof today (the OUT mouth at 930-931 is the ladder up, not the hatch).
7. Entry hint fits the hint box: no node-side width rule exists. BROWSER OWED textfit (see below).
