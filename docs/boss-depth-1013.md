# BOSS DEPTH AUDIT (rule B17) - 2026-10-13, read-only, base origin/master a0e14160

Lane claude/bossaudit (Sonnet). Source of the rule: scratch/brief-bossaudit-1013.md + the B17 line at the end of scratch/design-standard.md.
Nothing was run (no page, no browser, no server). Everything below was read from source; a node one-liner imported src/level.js / src/marks.js
only to list the LEVELS road order, each level's `rule` line, its `ents` vocabulary and the MARK table.

B17: from ACT III on a boss has >= 4 distinct TOLD attacks (5+ preferred) and ONE CENTRAL MECHANIC that is the LEVEL'S OWN verb/gimmick.
Act I exempt. "Distinct" = a different verb to answer (jump, block/parry, move off, break line of sight, use a prop).

## 0. How to read this

- Acts (from scratch/audit-keys.md section 3 + the `arc:` fields at src/level.js:7893/7899/7921/7952/7969): I = wood..kings (+rootway, underleaf); II = the crags,
  scree..crown (+ oreroad, minecart, storm); **III = the sea: longwater, reef, flotilla, hurricane, lamplit, deep, keep, causeway (+ harbor branch)**;
  **IV = the road inland: waymeet, towpath, canal, church, theatre, fair, fields, burial, witchlight, mage, fallingtower (+ undercrown, unburied, burning branches)**;
  **V = the desert: caravan, welltown, underwell, redgorge, glasssea, ksar, buriedcity, sealedpyramid.** Act III+ = in full; I-II = a short note table (section 4).
- N = real DISTINCT TOLD attacks counted from the boss's module/updater (not the marks.js count: phase variants and mark-less moves are folded/added by hand).
  I count a quiet told move that changes what you must DO (the Tollmaster's DARK, the Fog Knight's DOUBLE, a stance) as an attack; I do not count adds, phase
  transitions or environment hazards. `!` = yellow (shield turns it), `!!` = red (nothing does), `q` = quiet (told, no blow of its own).
- Verdicts: **STRONG** = N >= 4 and the central mechanic IS the level's verb, used in the fight. **OK** = N >= 4 and a real mechanic, but it is the boss's own / the
  hero-kit's rather than the level's (or the level's verb is only partly used). **REWORK** = N < 4, or no level mechanic at all. `queued` = Daniel already queued it.
- File refs: `M` = src/main.js, `L` = src/level.js, `B` = bestiary line (M, `desc:`). Other files are named in full.
